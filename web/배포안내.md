# 촬영 스케줄·완료보고 웹앱 — 사용 안내

## ✅ 배포 완료 — 지금 바로 쓸 수 있습니다

**웹 주소:** https://samkoo-shoot.vercel.app
(이전 주소 https://web-eta-nine-56.vercel.app 도 계속 열립니다)

- 전체공개 상태입니다. 주소만 알면 누구나(폰·PC) 접속해서 사용합니다.
- 일정·사진·완료보고서는 클라우드(Vercel Blob)에 저장되어, 어느 기기에서 보든 같은 내용입니다.
- 저장소 연결·배포는 이미 끝내 두었으니 사장님이 따로 설정할 것은 없습니다.

---

## 폰에서 쓰기 (촬영 현장)

1. 폰 브라우저(크롬/사파리)로 위 주소 접속 → **홈 화면에 추가**하면 앱처럼 씁니다.
2. **＋ 일정 추가**: 촬영명·촬영종류·제작사·관리자·촬영일시 입력.
3. 캘린더/목록에서 촬영을 누르면 상세로 이동:
   - **완료보고서 작성** 탭: `보양 및 세팅 / 촬영 / 철수 및 정리` 3개.
     사진 칸을 누르면 **카메라 촬영** 또는 **앨범 선택**. 기본 4칸, 아래 버튼으로 무제한 추가.
     (사진은 자동 저장됩니다.)
   - **📄 PDF 출력·공유**: PDF를 만들어 폰 공유창에서 **카카오톡·메일** 선택해 바로 전송.
   - **메일 내용 작성기** 탭: 일정 정보로 메일 문안 자동 작성 → **내용 복사** 버튼으로 붙여넣기.

> PC(데스크톱) 브라우저에서는 공유창 대신 PDF가 다운로드될 수 있습니다. 그때는 저장된 PDF를 첨부하세요.

## 앞으로 내용을 고치면 (개발용)

코드를 수정한 뒤 새 버전을 올리려면, `web` 폴더에서:

```powershell
cd C:\Users\user\Desktop\content-report\content-report\web
vercel --prod
```

- 내 컴퓨터에서만 미리 보려면: `npm run dev` → http://localhost:3000
  (이때는 데이터가 내 컴퓨터에만 저장됩니다.)
