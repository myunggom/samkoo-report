우리 건물 · 우리 설비

건물에서 직접 찍은 설비 사진을 참고로 다시 그려, 사진 속 설비가 실제로 쓰는 것과 같습니다. 사람은 머리부터 발까지 나옵니다.

1. 화면 구성

기존에는 목록 → 작업 → 자료 페이지로 여러 번 들어가야 했습니다. 새 사이트는 한 화면에서 작업을 고르고 자료를 넘깁니다.

왜 바꿨나 : SOP는 현장에서 QR로 휴대폰에 띄워 보는 자료입니다. 작은 화면에서 작업을 빨리 찾고, 사진으로 보호구와 자세를 확인할 수 있어야 합니다. 인쇄 · PDF 저장은 새 사이트에서도 그대로 됩니다.

2. 사진

같은 장면을 기존 사진(왼쪽)과 새 사진(오른쪽)으로 나란히 놓았습니다.

왜 바꿨나 : 교육 사진은 "이 설비 앞에서 이렇게 하라"를 보여 줘야 합니다. 다른 설비, 다른 현장, 잘린 사람은 따라 하기 어렵고 검토 때마다 지적이 나왔습니다. 그래서 실물 설비 사진을 참고로 넣고, 사람이 전신으로 나오게 했습니다. 다 만든 사진은 자동 검사로 잘림 · 겹침을 한 번 더 걸러 냅니다.

4. 사진 검수 — 계속 검토하고 고칩니다

사람이 사진을 한 장씩 보고 통과 · 문제를 표시합니다. 문제로 표시하며 남긴 메모와 예시 사진대로 다시 만들고, 다시 만든 사진은 검수 화면에 "다시 볼 것"으로 올라옵니다.

  1. 검수사진마다 통과 / 문제, 무엇이 틀렸는지 골라 메모
  2. 예시 사진 첨부말로 설명하기 어려운 설비(발신기 등)는 실물 사진을 붙임
  3. 다시 만들기메모 · 예시대로 다시 그리고 자동 검사로 잘림 · 겹침을 걸러 냄
  4. 다시 보기고친 사진이 "다시 볼 것"으로 올라와 다시 검수

5. 앞으로의 계획

  • 검수와 수정을 계속 반복합니다. 문제로 표시된 사진은 지적 내용대로 다시 만들어 다시 검수를 받고, 모든 사진이 통과할 때까지 이어 갑니다.
  • 실물 사진이 아직 없는 설비(옥상 공조기 · 폐수처리장 · 에어컨 · 보일러 · 쓰레기 압축기 · 곤돌라)는 우선 기존 사이트 그림을 참고해 만들었습니다. 현장 사진을 받는 대로 실제 설비 모습으로 바꾸겠습니다.
  • 각부 명칭 번호는 새 그림마다 위치를 다시 맞추고, 번호 · 이름이 안 맞는다고 지적된 곳을 먼저 고칩니다.
  • 전환 시점은 검수가 마무리되면 정하겠습니다. 그때 현장 QR 코드를 새 사이트로 연결하고, 일일 작업 보고서 · 결재는 기존 사이트에서 계속 씁니다.
