# 안전 SOP 새 디자인 시안

safety-sop.vercel.app 의 **페이지 구성은 그대로 두고 디자인만 바꾼** 시안입니다.
토큰과 용량을 아끼려고 **작업 한 건(c02 사다리 작업)** 만 담았습니다.

## 무엇이 달라졌나

| | 지금 사이트 | 이 시안 |
|---|---|---|
| 이동 | 목록 화면 → 작업 화면 → 네 페이지 | **왼쪽에 작업 목록 고정**, 오른쪽에 내용 |
| 네 가지 자료 | 각각 다른 페이지 | **본문 위 탭**으로 바로 전환 |
| 색 | 부문마다 다른 색 | **무채색 한 계열 + 포인트 1색(삼구 녹색)** |
| 포인트색 쓰임 | 장식 | **지금 보고 있는 곳**과 **반드시 지킬 것**에만 |
| 글꼴 | 맑은 고딕 | Pretendard (없으면 맑은 고딕) |

## 구성

```
index.html          화면 전체 (한 파일)
assets/data.js      c02 작업 자료만
assets/img/         그 작업 사진 18장
```

## 배포

Vercel 에서 이 저장소를 가져오고 **Root Directory 를 `sop-new`** 로 잡으면 됩니다.
빌드 설정은 없습니다. 정적 파일만 올라갑니다.

## 손볼 곳

- 작업을 늘리려면 `assets/data.js` 에 작업을 더 넣고 사진을 `assets/img/` 에 둡니다
- 색은 `index.html` 맨 위 `:root` 의 변수만 고치면 전체에 반영됩니다
- 라이트 · 다크 둘 다 들어 있습니다. 기기 설정을 따릅니다
