# ADR-0002: 업무일지는 PDF를 받아 사람이 직접 보낸다 (자동 메일 발송 없음)

**Date**: 2026-09-29
**Status**: accepted
**Deciders**: 운영자

## Context

일일 업무일지는 매일 고객사에 1장, 월말에 누적 자료를 보낸다. 웹 탭에서 계량값을 넣으면 PDF를 만들어 메일까지 자동으로 보내는 방안이 나왔다.

## Decision

앱은 **일일 PDF·월간 PDF를 만들어 내려받기(폰은 공유창)** 까지만 한다. 발송은 사람이 PDF를 확인한 뒤 카톡·메일로 직접 한다. 일일 PDF를 만들 때는 먼저 저장해서, 보낸 PDF와 저장본이 달라지지 않게 한다.

## Alternatives Considered

### Alternative 1: 제출 버튼으로 자동 메일 발송
- **Pros**: 한 번에 끝남
- **Cons**: 입력 실수·오타가 확인 없이 고객사로 나간다. 메일 발송 서비스(계정·키) 관리 필요
- **Why not**: 운영자 판단 — 잘못 발송할 수 있다

### Alternative 2: 정해진 시각에 자동 발송
- **Why not**: 위와 같은 위험이 더 크다(사람이 보지 않고 나감)

## Consequences

### Positive
- 오발송 위험 없음, 외부 메일 서비스 의존 없음

### Negative
- 매일 PDF를 받아 보내는 한 번의 수작업이 남는다

### Risks
- 다시 자동 발송을 붙이려면 "미리보기 → 확인 → 발송" 방식으로만 할 것
