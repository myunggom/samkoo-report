## 1. 배경

### 1.1 건물과 입주사 — 혼동 주의

| 건물 | 입주사 |
|---|---|
| **바이오 이노베이션 허브** (이 문서의 대상) | **프로젠 · 제넥신 · 셀리드** |
| 옆 건물 (1사옥) | 한독 · 제넥신 · 프로젠 |

두 건물 모두 제넥신·프로젠이 있어 섞이기 쉽다. `hgp-report/`·`web/`의 "한독·제넥신·프로젠"은 **옆 건물** 기준이므로 건드리지 말 것.

### 1.2 업무 흐름 (현재, 전부 수작업)

매달 사용월 다음 달에 작성한다. 예: 8월 사용분 → `09월 (08월 사용분)` 폴더.

1. 지난달 폴더를 복사해 새 달 폴더를 만들고 파일명의 월을 바꾼다
2. 각 회입분의 `작성방법!B7`에 **작성 월 1일**을 넣는다
3. 고지서(한전·열·수도·중수)를 보고 `고지서` 시트에 값을 받아 적는다
4. 원격검침 프로그램에서 기간별 자료를 내려받아 **`원격검침 DB` 시트에 시작지침·종료지침을 복사해 넣는다** ← 여기가 950칸
5. 수식이 계산한 3사 청구금액을 `00. 종합표`에 붙여넣고, 고지서 금액과 맞는지 검산한다

| 01 전기 | 원격검침 DB | 226 |

## 3. 원격검침 자료 (검침자료) 명세

### 3.1 파일 형식 — 함정 있음

- 확장자는 `.xls` 지만 **실제 내용은 SpreadsheetML 2003 (XML)** 이다. BIFF 파서(`xlrd`)로는 못 읽는다.
- **파일 끝에 널 바이트(0x00)가 붙어 나온다.** 제거하지 않으면 XML 파서가 터진다.
  ```python
  raw = open(path,"rb").read().replace(b"\x00", b"").rstrip()
  root = ET.fromstring(raw)
  ```
- 네임스페이스 : `urn:schemas-microsoft-com:office:spreadsheet`
- 셀 좌표는 `ss:Index` 속성으로 건너뛰며, `ss:MergeAcross` 가 있으므로 열 번호 계산에 반영해야 한다.
- **시트 이름이 기간이다** : `2026.07.25.00 ∼ 2026.08.24.24`

### 3.2 파일명은 믿을 수 없다

달마다 다르다. 실제 관측값:

| 폴더 | 파일명 앞부분 |
|---|---|
| 2026.08월 사용분 | `전기` `열` `수도` `중수` |
| 2026.07월 사용량 | `E` `H` `W` |
| 2026.01월 사용량 | `설비`(4개) `전기`(2개) |

→ **파일명이 아니라 내용과 기간으로 판별해야 한다.**

### 3.3 항목 판별 규칙 (검증됨)

1. 머리글에 `전기` 묶음이 있으면 → **전기형**
2. 그 외는 **물형**(수도·열·중수가 완전히 같은 양식). 기간 모양으로 가른다.

| 항목 | 기간 모양 | 실제 예 |
|---|---|---|
| 열 | 달 1일 ~ 말일 | 2026.08.01 ~ 2026.08.31 |
| 수도 | 20일 이후 시작, 다음달 중순 끝 | 2026.07.25 ~ 2026.08.24 |
| 중수 | 45일 초과 (2개월 주기) | 2026.07.01 ~ 2026.08.31 |

보강 : 회입분 `고지서!D5`(사용기간)와 정확히 일치하면 그것을 우선한다.

### 3.4 칸 배치 (0-based)

**전기형**

| 번호 | 내용 |
|---:|---|
| 0 | NO |
| 1 | 동 (예: `A동 공용`, `A동 셀리드`) |
| 2 | 호 (분전반명, 예: `LN GY B3A`) |
| 3 | **시작지침** |
| 4 | **종료지침** |
| 5 | CT |
| 6 | 계기사용량 kWh |
| 7 | 부하사용량 kWh |
| 8 | 회전 |

**물형** — 머리글 2행에 묶음명, 3행 `검침값`/`사용량`, 4행 `시작지침`/`종료지침`/단위. 자료는 5행(1-based)부터.

| 묶음 | 시작지침 | 종료지침 | 사용량 |
|---|---:|---:|---:|
| 수도/중수 | 3 | 4 | 5 |
| 온수 | 6 | 7 | 8 |
| 가스 | 9 | 10 | 11 |
| 환탕 | 12 | 13 | 14 |
| 냉난방 | 15 | 16 | 17 (MWh) |

값이 `-` 인 칸은 미설치 계량기다. 그대로 `-` 를 넣는다.

## 4. 회입분 엑셀 명세

### 4.1 시트 구성

| 파일 | 시트 |
|---|---|
| 01 전기 | 작성방법 / 각 사 전기사용량 및 요금 / 고지서 / **원격검침 DB** / 고객사별 사용량 / 공용부 사용량 / 프로젠·제넥신·셀리드 청구금액 |
| 02 열 | 작성방법 / 각 사 열사용량 및 요금 / 고지서 / **원격검침 DB** / 사용량 / 3사 청구금액 |
| 03 수도 | 작성방법 / 각 사 수도사용량 및 요금 / 고지서 / **수도 원격검침 DB** / **온수 원격검침 DB** / 고객사별 사용량 / 3사 청구금액 |
| 04 중수 | 작성방법 / 고지서 / 각 사 중수사용량 및 요금 / **원격검침 DB** / 사용량 / 3사 청구금액 |

### 4.2 ⚠️ 원격검침 DB 시트에는 표가 2개 이상 있다

**두 번째 표부터는 전부 수식이다. 절대 쓰지 말 것.**

```
전기 원격검침 DB 4행 머리글:
  B NO | C 용도 | D 분전반명 | E 사용처 | F CT | G 전월검침 | H 당월검침 | I 당월사용량
  K NO | L 용도 | M 분전반명 | N 사용처 | O CT | P 전월검침 | Q 당월검침 | R 당월사용량  ← 2번째 표
  실제 수식 : I5 = (H5-G5)*F5 ,  P5 = G5 ,  Q5 = $V5 ,  R5 = (Q5-P5)*O5
```

표 경계는 **머리글 줄의 `NO` 칸 위치**로 가른다. 첫 `NO` ~ (두 번째 `NO` − 1) 까지만 다룬다.

### 4.3 쓸 칸

| 시트 | 자료 시작행 | 전월검침 | 당월검침 | 비고 |
|---|---:|---|---|---|
| 01 원격검침 DB | 5 | **G** | **H** | F=CT (쓰지 않음) |
| 02 원격검침 DB | 6 | **F** | **G** | 묶음 라벨 `냉난방 [㎥]` (실제 단위는 MWh) |
| 03 수도 원격검침 DB | 6 | **F** | **G** | 묶음 `수도 / 중수[㎥]` |
| 03 온수 원격검침 DB | 6 | **F** / **I** | **G** / **J** | F·G=온수, I·J=환수(←검침자료 `환탕`) |
| 04 원격검침 DB | 6 | **F** | **G** | 묶음 `중수 [㎥]` |

**묶음 라벨은 항상 `전월검침` 과 같은 열의 위쪽 행에 있다.** 옆 열까지 뒤지면 `1. 원격검침 DB 자료 입력` 같은 안내문을 집는다(실제로 겪은 버그). 전기 DB는 라벨이 없으므로 항목명(`전기`)으로 되돌린다.

### 4.4 `작성방법!B7` 한 칸이 모든 기간을 만든다

`B7` = **작성 월 1일**(= 사용월 1일). 여기서 고지서 사용기간·납부일자가 전부 수식으로 계산된다.

```
01 전기 : AD2 = 작성방법!B7
          AD3 = 작성방법!B7+9
          AE3 = EOMONTH(AD3,0)+9
          AF3 = TEXT(AD3,"yyyy.mm.dd") & " ~ " & TEXT(AE3,...)
          D5  = AF3        → "2026.08.10 ~ 2026.09.09"
02 열   : D5 = V5          → "2026.08.01 ~ 2026.08.31"
03 수도 : D5 = V6          → "26.07.25 ~ 26.08.24"
```

B7만 넣으면 4개 파일 기간이 알아서 맞고, 검침자료 짝맞추기도 "기간 일치"로 확정된다.

### 4.5 검산 지표

- `작성방법` 시트의 **미검침분** (전기는 `I9`/`I20`, 나머지는 `I9`) = 고지서 사용량 − 원격검침 합계
  - **음수면 오류다.** 원격검침 합계가 고지서보다 크다는 뜻 → 계기 오류·중복 집계
  - 단, **전기의 첫 미검침분은 정상적으로 음수**다(태양광 발전량 때문). 전기는 2개 표가 있고 두 번째(한전+태양광 기준)가 양수여야 한다.
- `00. 종합표` : 항목마다 `요금 합계` 와 `고지서 요금` 을 비교
  ```
  G26 = G10+G17+G24            (3사 합계)
  G27 = 고지서 금액 (직접 입력)
  H26 = G26-G27                (차액)
  H27 = ROUNDDOWN(G26,-1)=ROUNDDOWN(G27,-1)   → TRUE 여야 함
  ```
  종합표는 **값 붙여넣기 방식**(다른 파일을 참조하지 않음)이므로 자동 작성이 가능하다.

### 4.6 고지서 시트

- **C~K 열 = 고지서 본문** (받아 적는 값)
- **L 열 이후 = 12개월 추이표** (월별 기록. 매달 한 줄 추가 — 아직 수동)

전기 고지서 본문에 들어가는 것 : 기본요금(kW·단가), 역율요금, 부하시간대별(경부하·중간부하·최대부하 × 여름철·봄가을철·겨울철) 사용량·단가, 연료비조정액, 기후환경요금, 진상역률료, 요금계, 부가세, 전력기금, 고지금액.

> 건물은 **한전 일반용(을) 고압A, 계시별 요금제**. PT비 13200/110V, CT비 150/5A, 배율 3,600. 태양광 발전 있음.

## 5. 보정표 (`보정.txt`)

검침자료 폴더에 두는 텍스트 파일. 계량기가 틀리게 재는 경우를 바로잡는다.

```
# 항목 | 계량기명 | 시작지침 | 종료지침 | 묶음(보통 생략)
#   항목 : 전기 / 열 / 수도 / 중수
#   비워 두면 검침자료 값 그대로
#   묶음 : 수도 회입분의 '온수'·'환수' 칸을 고칠 때만

수도 | 24시간 냉각탑 보급수 | 계량률 19.40%
```

**계량률** = 계량기가 실제의 몇 %만 재는지. 사용량을 `/비율` 로 역산해 종료지침을 다시 만든다.

현재 등록된 것 1건:

| 계량기 | 사유 | 근거 |
|---|---|---|
| 24시간 냉각탑 보급수 (수도) | 실제의 19.40%만 계량 | 회입분 `03 고지서!D49` 사장 메모 "냉각탑 수도 계량기 19.4%" |

검증 : 검침자료 사용량 110.70 ÷ 0.1940 = 570.62 → 종료지침 126.64 + 570.62 = **697.26** (사장이 손으로 넣은 값과 정확히 일치)

## 6. 이미 만들어진 로컬 도구

`tools/` 에 있다. **이것들은 완성·검증 끝. 다시 만들 필요 없다.**

### 6.1 `tools/meter_fill.py`

검침자료 → 회입분 `원격검침 DB` 채우기.

```bash
python meter_fill.py --검침 "<검침자료 폴더>" --회입분 "<월 폴더>" --출력 "<새 폴더>"
python meter_fill.py ... --대조        # 쓰지 않고 원본과 값만 견줌
python meter_fill.py ... --기간무시    # 양식에서 갓 복사해 사용기간이 지난달일 때
```

- **실제 엑셀을 띄운다(xlwings).** 이유는 7장.
- **원본을 절대 고치지 않는다.** 항상 사본을 만들어 사본에만 쓴다.
- 짝맞추기는 **NO 기준**, 이름은 검증용(다르면 경고)
- 경고 종류 : 검침자료에 없는 계량기 / 회입분에 칸이 없는 계량기 / 번호 없이 값만 있는 줄 / 이름 불일치 / **검침값 역행** / 미검침분 음수

### 6.2 `tools/meter_month.py`

검침자료 폴더 하나만 주면 그 달을 통째로 만든다.

```bash
python meter_month.py --검침 "<검침자료 폴더>"
python meter_month.py --검침 "<...>" --양식 "<양식 월 폴더>" --출력 "<새 폴더>"
```

순서 : 사용월 판별 → 새 달 폴더 생성(양식 복사 + 파일명 월 치환) → `작성방법!B7` 입력 → 원격검침 DB 채우기 → `고지서_입력표.txt` 생성(또는 채워진 것 적용)

`고지서_입력표.txt` 형식 — **지난달 값이 같이 적혀 있어** 비교해 채우기 쉽다. 비우면 지난달 값 유지.

```
항목 | 칸 | 설명 | 지난달값 | 이번달값
전기 | F15 | 여름철 | 26227 |
열   | F11 | 난방용금 | 73371 |
수도 | K17 | 당월지침 [㎥] | 1686 |
```

## 9. 이번 작업 — `report/` 에 수도광열비 탭 만들기

### 9.1 참고할 기존 코드

- `report/lib/billing.ts` + `report/app/billing/page.tsx` + `report/app/api/billing/`
  실비 청구(점검비 입주사 분담) 모듈. **입주사 이름·분담 비율을 코드가 아니라 저장소 데이터(`shares`)에 두는 방식**을 그대로 따를 것. 공개 저장소에 입주사 정보를 넣지 않는다.
- 파일 업로드는 `report/app/api/blob-upload/` + `@vercel/blob` 패턴 사용
- 순수 계산은 `lib/*.ts`, 자가 점검은 `lib/*.check.mts` 규칙을 따른다 (기존 파일들이 그렇게 돼 있음)

### 9.2 데이터 모델 (제안)

```ts
type UtilityKind = "전기" | "열" | "수도" | "중수";

type UtilityMonth = {
  month: string;              // 사용월 "2026-08"
  bills: Record<UtilityKind, BillInput>;
  feeds: FeedFile[];          // 업로드한 검침자료
  checks: CheckResult[];      // 검증 결과
  status: "작성중" | "검증완료" | "엑셀완료";
  updatedAt: string;
};

type BillInput = {
  period?: { from: string; to: string };   // 검침자료에서 자동 추출
  amount?: number;                          // 고지금액 (VAT 포함)
  usage?: number;                           // 고지서 사용량
  cells: Record<string, number | string>;   // 고지서 시트 칸 → 값 ("F15": 21721)
  note?: string;                            // 증감원인분석 · 특이사항
};

type FeedFile = {
  name: string; blobUrl: string;
  kind: UtilityKind;                        // 기간 모양으로 자동 판별
  period: { from: string; to: string };
  meters: { no: number; dong: string; name: string;
            start: number | "-"; end: number | "-"; usage: number | "-" }[];
};

type Fix = {                                 // 보정표 (보정.txt 대체)
  kind: UtilityKind; meter: string;
  rate?: number;                             // 계량률 0.194
  start?: number; end?: number;              // 직접 지정
  group?: string;                            // 온수 / 환수
  reason: string;
};
```

### 9.3 화면 요구사항

1. **월 선택** — 사용월 기준. 과거 달 열람 가능.
2. **검침자료 업로드** — `.xls` 여러 개 드래그. 올리면 즉시
   - 기간을 읽어 **전기/열/수도/중수 자동 분류** (3.3 규칙) 후 화면에 표시
   - 계량기 목록·사용량 파싱 결과 표시
   - 잘못된 달 자료면 경고
3. **고지서 값 입력** — 항목별 폼. **지난달 값을 옆에 회색으로** 보여준다(비교해 채우기 쉽게). 비우면 지난달 값 유지.
4. **검증 결과 패널** — 아래 9.4 규칙을 전부 돌려 통과/경고를 보여준다. 휴대폰에서도 읽히게.
5. **보정표 관리** — 계량률·고정값 등록/수정. 사유 필수.
6. **로컬 작업용 내려받기** — 그 달 데이터를 JSON 하나로. 로컬 `tools/` 가 이걸 읽어 엑셀을 완성한다.
